# ORDIN AI — архитектура системы

Этот репозиторий — единое место хранения визуальной архитектуры ORDIN.

Здесь будут лежать:

- схемы в формате `.drawio` для diagrams.net;
- описания логики в Markdown;
- журнал изменений архитектуры;
- шаблоны для новых схем.

## Как пользоваться

1. Открыть diagrams.net: https://app.diagrams.net/
2. Выбрать `File → Open From → GitHub`.
3. Найти репозиторий `ORDIN-AI/ordin-ai-architecture`.
4. Открыть нужный файл из папки `схемы`.

## Главные файлы

- `схемы/01_Главная_карта_системы.drawio` — общая карта AI-системы ORDIN.
- `схемы/02_Карта_данных.drawio` — откуда берутся данные и куда они идут.
- `схемы/03_Процесс_от_заявки_до_денег.drawio` — коммерческий и производственный процесс.
- `схемы/04_Карта_AI_ролей.drawio` — роли AI-команды ORDIN.

## Принцип

Не плодим хаос. Одна схема = один смысл.

Если схема изменилась — обновляем файл и фиксируем изменение в журнале.
