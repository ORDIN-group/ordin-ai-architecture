# Обзор архитектуры ORDIN AI

## Назначение

Этот документ описывает, как устроена AI-система ORDIN на верхнем уровне.

Система нужна не ради красивой автоматизации, а ради управляемости бизнеса:

- быстрее видеть важные сигналы;
- понимать связи между клиентами, сделками, подрядчиками и деньгами;
- снижать инженерные и управленческие риски;
- не тонуть в таблицах, скриптах и workflow.

## Базовый контур

```text
ChatGPT
↓
n8n / Albato
↓
Apps Script
↓
ORDIN_AI_REGISTRY
↓
Google Sheets
↓
AI-агенты ORDIN
↓
решения / задачи / действия
```

## Роль GitHub

GitHub используется как хранилище архитектуры:

- схемы `.drawio`;
- описания `.md`;
- журнал изменений;
- шаблоны.

GitHub не заменяет Google Sheets и Bitrix.

```text
Bitrix = источник операционных данных
Google Sheets = аналитический слой
GitHub = архитектурная документация
ChatGPT = архитектор и редактор
```

## Главный принцип

Любое усложнение системы должно вести к управляемости, деньгам или снижению риска.

Если схема, таблица или автоматизация не помогает принимать решения — это мусор, даже если выглядит красиво.
